# FORGE · online fitnesscoaching

De website van FORGE: persoonlijke online fitnesscoaching voor vrouwen en mannen, met de voedingsapp erin.

**Live:** https://ywahyian.github.io/forge-coaching/

## Wat zit hier

- `index.html`: de volledige website in één bestand. Afbeeldingen, lettertypes en de voedingsapp zitten erin, er zijn geen andere bestanden nodig.
- `og-image.jpg`: de preview-afbeelding die verschijnt als je de link deelt (WhatsApp, iMessage, sociale media).

## Bijwerken

1. Open deze repository op GitHub en kies **Add file > Upload files**.
2. Sleep de nieuwe `index.html` erin. Hij vervangt de oude.
3. Klik op **Commit changes**. Na een minuut of twee staat de nieuwe versie online.

## Goed om te weten

- De voedingsapp (`#/voeding-app`) vraagt een toegangscode. Codes horen nooit in deze repository.
- Wat bezoekers in de app invullen, blijft op hun eigen toestel. Er draait geen server.
